# Медиа-Пульс

## Проблема

Журналисты, аналитики и PR-специалисты ежедневно сталкиваются с большим потоком публикаций из разных источников. Вручную просматривать тысячи новостей, находить важные темы и замечать изменения в повестке долго и сложно; из-за этого значимые события легко пропустить.

## Целевая аудитория

- **Журналисты и редакторы** — для мониторинга новостей и поиска тем для материалов.
- **Аналитики** — для изучения динамики публикаций и распределения внимания по темам и источникам.
- **PR-специалисты** — для наблюдения за упоминаниями, реакцией медиа и изменениями информационной повестки.

## Ключевые функции MVP

1. **Умная новостная лента:** сбор новостей из RSS-источников, автоматическая категоризация с помощью ИИ и просмотр публикаций в едином интерфейсе.
2. **Дашборд:** графики по источникам, категориям и активности публикаций во времени.
3. **Поиск и фильтрация:** поиск по заголовкам и отбор новостей по периоду, источнику и категории.

## Ценность продукта

«Медиа-Пульс» сокращает время на сбор и первичный анализ новостей. Пользователь быстрее видит основные темы и изменения повестки, может сосредоточиться на интерпретации событий и принятии решений вместо ручного просмотра множества лент.
