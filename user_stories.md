# User Stories: «Медиа-Пульс»

## US-01. Фильтрация по категории

**Приоритет:** Must have

**История:** Как аналитик, я хочу фильтровать новости по категории, чтобы быстро изучать публикации на интересующую тему.

**Критерии приёмки:**

```gherkin
Feature: Фильтрация новостей по категории

  Scenario: Показать новости выбранной категории
    Given в ленте есть новости категорий "Политика" и "Экономика"
    When аналитик выбирает категорию "Экономика"
    Then в списке остаются только новости категории "Экономика"
    And число найденных новостей соответствует отфильтрованному списку
```

## US-02. Просмотр графиков

**Приоритет:** Must have

**История:** Как аналитик, я хочу видеть графики публикационной активности и распределения новостей по категориям, чтобы замечать изменения и популярные темы.

**Критерии приёмки:**

```gherkin
Feature: Аналитические графики

  Scenario: Построить графики по доступным новостям
    Given в системе есть новости с датами публикации и категориями
    When аналитик открывает дашборд
    Then он видит график количества публикаций по дням
    And он видит распределение публикаций по категориям
    And подписи графиков и значения доступны для выбранного набора данных
```

## US-03. Поиск новостей

**Приоритет:** Must have

**История:** Как журналист, я хочу искать новости по словам в заголовке, чтобы быстро находить публикации по нужному событию.

**Критерии приёмки:**

```gherkin
Feature: Поиск по заголовку

  Scenario: Найти новость по ключевому слову
    Given в ленте есть новость с заголовком "Открытие нового музея"
    When журналист вводит в поиск слово "музея"
    Then в результатах отображается эта новость
    And новости, заголовки которых не содержат это слово, не отображаются

  Scenario: По запросу нет совпадений
    Given в ленте нет заголовков с введённым словом
    When журналист выполняет поиск
    Then система показывает пустое состояние с сообщением, что новости не найдены
```

## US-04. Чтение полной новости

**Приоритет:** Must have

**История:** Как журналист, я хочу открыть полный текст новости у первоисточника, чтобы проверить детали и контекст публикации.

**Критерии приёмки:**

```gherkin
Feature: Переход к первоисточнику

  Scenario: Открыть полную новость
    Given у новости в ленте есть действующая ссылка на источник
    When журналист нажимает ссылку или кнопку "Читать источник"
    Then полный материал открывается на сайте издания в новой вкладке
    And исходная страница «Медиа-Пульс» остаётся открытой
```

## US-05. Фильтрация по периоду

**Приоритет:** Should have

**История:** Как аналитик, я хочу выбирать период публикаций, чтобы сравнивать повестку за нужные даты.

**Критерии приёмки:**

```gherkin
Feature: Фильтрация по периоду

  Scenario: Показать новости за выбранный период
    Given в ленте есть новости до, внутри и после выбранного периода
    When аналитик задаёт начальную и конечную даты
    Then в списке отображаются только новости с датой публикации внутри периода
    And графики пересчитываются по тому же периоду
```
